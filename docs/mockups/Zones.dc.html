Last assigned wins. The other lane is released and shows a notice. Changing a zone never changes the stored music.
Pattern zones
Three keys are chord tones 1, 2 and 3 of the current chord, so there are no wrong notes. Bass and pad read the same chord, each in its own register.
Lead zones
Two zones give six scale degrees. ← → slide the window, ↑ ↓ change octave, ⇧ + key plays a chromatic passing tone.
Chord entry and rollover
Arming the chord lane makes the number row degrees I–VII. Laptop keyboards can drop keys when several are held, so MIDI keyboard input is the answer for dense playing.
